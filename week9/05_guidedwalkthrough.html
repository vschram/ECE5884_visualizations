Bridge from Week 8 and OFDM parameter selection

The subcarrier spacing is a compromise between CP overhead and Doppler, and coding supplies the frequency diversity

The delay spread fixes the CP in seconds, so a longer useful symbol Ts = 1/Δf spends a smaller fraction of each symbol on it. The same small Δf becomes a problem once the Doppler spread BD is no longer much smaller than it. Per-subcarrier equalization removes ISI but leaves the fades in place, so coding and interleaving across subcarriers are needed to obtain frequency diversity.

                      Multiple access techniques

                      Every scheme divides the same ≈ 2BT signal dimensions, by frequency, by time, or by code

                      FDMA gives each user a narrow channel, TDMA a repeating slot of the full band, and CDMA a spreading code over the whole time–frequency plane. OFDM-based access uses the same ideas on a digital grid: OFDMA assigns disjoint subcarrier sets, OFDM-TDMA assigns whole OFDM symbols, and MC-CDMA spreads each symbol across subcarriers. The CDMA panels show why code separation depends on chip synchronization and on power control.

                            Orthogonal frequency-division multiple access

                            Give each user the resource blocks where its channel is strong, and choose the modulation for each one

                            Each user reports CQI, and the base station assigns disjoint resource blocks of 12 subcarriers and picks an MCS for each. Users see different frequency responses, so a channel-aware scheduler can move each user onto its strong RBs and use a higher-order constellation there. The rates below use the exercise numerology, Tsym = 57.6 µs. On the downlink one IFFT keeps adjacent users orthogonal. On the uplink each handset has its own timing and oscillator.

                                    Single-carrier FDMA (DFT-spread OFDM)

                                    Move the IDFT from the transmitter to the receiver: the handset gets a low PAPR, and every symbol sees the average noise gain

                                    SC-FDMA puts an M-point DFT before the subcarrier mapper, and the N-point IFFT then largely undoes it, so the handset transmits the QAM symbols one after another like a single carrier. OFDMA and SC-FDMA send the same rate on the same subcarriers. At the base station the equalizer works per subcarrier and an M-point IDFT follows it, so each detected symbol sees the average ZF noise gain.
