Week 10 · OFDM Design, PAPR, and Multiple Access with OFDMA and SC-FDMA

Follow the Week 10 sequence: select the OFDM parameters (subcarrier spacing and symbol duration), use coding across subcarriers to obtain frequency diversity, examine why summing N subcarriers can produce a high peak-to-average power ratio (PAPR), compare multiple-access schemes, schedule users on OFDMA resource blocks, and use DFT spreading (SC-FDMA) to reduce the uplink PAPR.

Recap of OFDM and OFDM parameter selection

Subcarrier spacing balances cyclic-prefix overhead against sensitivity to Doppler spread

The channel delay spread sets the minimum cyclic-prefix (CP) duration; allow a margin for timing uncertainty. Increasing the useful symbol duration Ts = 1/Δf therefore reduces the CP overhead, but the corresponding smaller subcarrier spacing Δf increases sensitivity to Doppler spread BD. Per-subcarrier equalization removes intersymbol interference (ISI) when the CP is long enough, but it does not remove frequency-selective fades. Coding and interleaving across subcarriers are therefore needed to obtain frequency diversity.

        Peak-to-average power ratio

        Occasional alignment of N subcarrier contributions creates large power peaks

        Each inverse fast Fourier transform (IFFT) output sample is the sum of N subcarrier contributions represented as phasors. For sufficiently large N, the central limit theorem (CLT) gives an approximately complex Gaussian sample with E|x[n]|² = EX/N; consequently, its envelope is approximately Rayleigh distributed. For equal-magnitude symbols such as QPSK, the sampled PAPR is bounded by N, reached when all phasors align, but random data almost never produce this extreme case. The practical quantity is Pr(PAPR ≥ P0): the probability that the PAPR exceeds the amplifier's available input back-off.

                Multiple access techniques

                Users share the available bandwidth by frequency, time, or code

                Frequency-division multiple access (FDMA) gives each user a narrow channel, time-division multiple access (TDMA) gives each user a repeating time slot, and code-division multiple access (CDMA) separates users by spreading codes. OFDM-based access applies the same principles to a digital time–frequency grid: OFDMA assigns disjoint subcarrier sets, OFDM-TDMA assigns complete OFDM symbols, and multicarrier CDMA (MC-CDMA) spreads each data symbol across subcarriers.

                              Orthogonal frequency-division multiple access

                              Assign each resource block to a user with favourable channel conditions and select a suitable modulation

                              Each user equipment (UE) reports a channel-quality indicator (CQI). The base station assigns disjoint resource blocks (RBs) of 12 subcarriers and selects a modulation and coding scheme (MCS) for each RB. Because users experience different frequency responses, a channel-aware scheduler can assign an RB to a user whose channel is strong on those subcarriers. Here, each RB is the lecture exercise’s simplified group of 12 subcarriers, allocated every symbol with Tsym = 57.6 µs. An actual LTE RB spans 12 subcarriers over a 0.5 ms slot. On the downlink, all users' subcarriers are generated by one synchronized IFFT. On the uplink, each handset has an independent timing reference and oscillator.

                                      Single-carrier FDMA (DFT-spread OFDM)

                                      DFT spreading produces a lower-PAPR uplink waveform and distributes each data symbol across the allocated subcarriers

                                      SC-FDMA applies an M-point discrete Fourier transform (DFT) before subcarrier mapping. For localized mapping, the subsequent N-point inverse DFT (IFFT) produces a waveform with a single-carrier structure and typically lower PAPR than OFDMA. At the base station, a one-tap equalizer operates on each subcarrier and an M-point inverse DFT (IDFT) reconstructs the QAM symbols. With zero-forcing (ZF) equalization, each reconstructed symbol experiences the average noise enhancement across the allocated subcarriers.
