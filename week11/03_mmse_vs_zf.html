Minimum mean-square error versus zero-forcing detection

Assuming perfect channel-state information at the receiver (CSIR) and a channel with linearly independent columns, zero-forcing (ZF) detection removes inter-stream interference exactly but can amplify noise. Minimum mean-square error (MMSE) detection allows some residual interference when doing so produces a higher output signal-to-interference-plus-noise ratio (SINR).

Scenario

H = [ 1   ρ ;   ρ   1 ]

ρ is a matrix coefficient. The normalised correlation between the channel columns is 2ρ/(1+ρ²).
